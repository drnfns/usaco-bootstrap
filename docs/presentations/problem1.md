# problem 1: the palindrome game

topic: usaco bronze bootstrap | presenter: me!

---

## game definition

- start with S stones; S >= 1
- take turns removing any palindrome; p <= S
- palindrome: same from forward and back
- player who can't move anymore loses

---

## winning / losing position

- winning: at least one move to a worsing state!
- losing: all moves go to winning states.
- observation: ends
