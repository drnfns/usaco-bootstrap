this is the repository contains content for the usaco bootstrap, completed by
me.

## structure

the problems can be found in the `docs` folder, and the solutions can be found
in the `src` folder.

the explanation for the solutions can be found in the `docs` folder ending in
`.ex.md`.

## license

only the source code in the `src` directory is licensed under the unlicense,
which can be found in the `LICENSE` file. **the problem contents in the `docs`
the unlicense does not apply** as they are created by usaco. the files ending in
`.ex.md` are the only files that are exceptions (under the unlicense) as they
are created by me.
