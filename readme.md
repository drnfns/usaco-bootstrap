this is the repository contains content for the usaco bootstrap, completed by
me.

## structure

the problems can be found in the `docs/problems` folder, and the solutions can
be found in the `src` folder.

the explanation and presentation slides file for the solutions can be found in
the `docs/explanations` and `docs/presentations` folders respectively.
